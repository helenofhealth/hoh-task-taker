# Pink Task Flow

I want to create a task tracker like Click Up where I can track the tasks progress (Requested, In Progress, Review Completed). I also want to be able to track the time in there. When I stop the timer it should update to increments of 15 mns. On the top I want to show how many hours the clients have bought and their remaining hours. We will call this time report. The tasks should have their assigned owner, followers, being able to be marked as recurrent. When is the start date and end date. Also I want to be able to leave comments in there, have a description, upload documents. I want also to be able to drag and drop the tasks from one status to another. In general I want something to look like Click Up but being more user friendly. What else do you need from me to be able to built it? The attached file shows an interface that I like. I'd like to use though instead of blue the pink. I want it to look pretty not only professional. We will also create an AI for when someone wants to assign a project.
